# cli-todolist

## What is this?
A cli-todolist script with keybind-based navigation. Currently this script is made for and tested in the sway window-manager. Support for more window-managers will be coming in the future.

## installation

1. clone repo:
```bash
git clone https://github.com/emdeby/cli-todolist.git
```
2. change directory:
```bash
cd cli-todolist/
```
3. run install.sh:
```basg
./install.sh
```
